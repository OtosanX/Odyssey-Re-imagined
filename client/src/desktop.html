Host your own MMO server

How to host and invite players
  1. Choose a server name, port and world folder. Use a different folder for each separate world; back it up to preserve accounts and inventories.
  2. Set a join password for a locked server, or remove the lock for open access. This is separate from players’ account passwords.
  3. Save settings and start the server. Keep this app and PC running.
  4. On your home network, share your PC’s LAN address and game port. For other networks, allow the game port through the firewall and forward that TCP port on your router to this PC. If your ISP uses CGNAT, you need a reachable connection or a VPN/tunnel.
  5. Friends choose MMO, add your address and port, and join. Give them the server password separately if it is locked. Never expose the admin port.
  6. After editing maps, save and stop the server before restarting it. Changing the folder selects a different server world; it does not transfer characters.
