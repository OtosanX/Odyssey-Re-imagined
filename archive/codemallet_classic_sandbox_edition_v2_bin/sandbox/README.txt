Welcome to the sandbox!

Version 2.0

To get started, open the ClassicServer folder and run server.exe.  This will open the game server.
Next, go to the ClassicClient folder and run ody.exe.

You may now create an account and log in.

Some available god commands:
/god editmap
/god editmonster
/god editobject
/god warp Map X Y
/god setmysprite #
/god setmystatus #
